# 업로드 핵심 안내·권리 확인 초안

작성일: 2026-10-21. 배포 전 검증 중인 내부 초안이다. 최종 국외 이전 고지 범위와 법적 근거가 미확정이며 정식 공표·정책 활성화 완료를 뜻하지 않는다. 현재 서비스의 영상·음원·사진에 적용하며 새로운 미디어 기능을 추가하지 않는다.

## 처음 올릴 때 보여 줄 안내

> 올린 자료는 밴드 기록으로 저장됩니다. 영상은 재생 호환성과 데이터 절약을 위해 변환되거나 M4A 음원이 추출될 수 있습니다. 새 업로드의 기본 공개 범위는 멤버 전용입니다. 전체 공개를 선택하면 비회원도 볼 수 있습니다. 밴드를 탈퇴해도 자료는 자동으로 삭제되지 않으며, 개인정보·권리 침해와 관련된 삭제 요청은 문의처로 보낼 수 있습니다.

약관·개인정보처리방침 링크를 제공한다. 서비스 저장·변환·선택 범위 재생에 필요한 이용허락을 설명하고 서비스와 무관한 홍보·재판매·AI 학습까지 허락받는 문구를 넣지 않는다.

## 파일 묶음별 확인

선택한 파일과 대상 밴드, 적용할 공개 범위를 보여 주고 다음 취지로 확인한다.

> 이 파일을 선택한 범위로 게시·공유할 권한이 있고, 필요한 출연자·권리자의 허락을 받았습니다.

- 파일 선택·드롭 즉시 전송하지 않고 선택 → 확인 → 업로드 시작 흐름을 제공한다.
- 묶음의 파일·밴드·계정·공개 범위가 바뀌면 예전 확인을 그대로 재사용하지 않는다.
- 여러 파일에는 한 번의 확인을 적용할 수 있다. 완료 재시도·화면 이동 때문에 같은 확인을 반복 강요하지 않는다.
- 커버곡 원곡·반주·타인의 녹음에 필요한 권리와, 촬영자·출연자의 허락을 구분한다. 체크 하나로 실제 권리를 새로 만들지는 못한다.
- 장문의 개인정보 포괄 동의를 매번 받지 않는다. 필요한 처리 근거·고지는 방침에서 구분한다.

## 전체 공개로 확대할 때

> 전체 공개로 바꾸면 이 자료를 비회원도 볼 수 있습니다. 변경할 범위에 필요한 허락이 있는지 다시 확인해 주세요.

파일 자체뿐 아니라 곡·합주 등 부모의 공개 변경으로 실제 접근 범위가 넓어지는 동작을 검토한다. 멤버 전용 부모가 제한하는 최종 유효 범위도 설명한다. 기존 공개 자료를 일괄 변경하지 않는다.

## 기존 이용자·기존 자료

기존 계정도 정책 적용 후 새 업로드에는 필요한 확인을 받는다. 현재 가입 정책의 cutoff 면제를 모든 새 업로드에 자동 적용하지 않는다. 이전 영상의 확인 이력을 소급 생성하지 않으며 새 확인으로 과거 자료의 권리 문제가 해결됐다고 안내하지 않는다.

## 구현·출시 확인

서버가 적용 버전·행위자·밴드·업로드 대상·공개 범위를 검증하고 최소 기록을 남긴다. 업로드 확인 기록은 해당 콘텐츠가 유지되는 동안 보존하고 삭제 확정 후 30일 이내 정리한다. 재시도 멱등성, 진행 중 capability·완료·취소 계약을 보존한다. 기록용 운영 DB 변경과 정책 설정 활성화는 각각 승인된 범위와 최종 게이트를 따른다.
