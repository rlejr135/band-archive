# 남은 작업 요약 — 2026-10-21

총괄이 현재 코드·문서와 사용자 보류 결정을 대조한 결과다. 과거 문서의 전환 전 설명을 현재 미완료 상태로 해석하지 않으며, 이 목록만으로 구현·운영 변경을 시작하지 않는다.

| 항목 | 남은 일 | 상태·진행 조건 |
|---|---|---|
| 일반 가입 신청 | 검색 화면의 `requestBand` 폼을 공통 밴드 소개 페이지로 옮겨 신청 흐름 통합. 필수 이름·자기소개·초대 링크 자체의 재구현은 아님. | **미구현:** 기존 개편 계획의 5단계. 가입 오류는 재개 시 실제 요청·응답으로 재현하고 현재 원인을 확인. |
| 밴드별 색상 프리셋 | 공통 화면 구조를 유지하며 프리셋 선택·저장·미리보기 및 `theme_key` 연결. | **미구현:** 기존 공통 디자인 정리와 별도. |
| 생성 요청 승인·거절 메일 | outbox 모델·migration만 있으며 이벤트 연결, 발송 worker, SMTP 연결, 발송 결과 UI가 남음. | **기반만 구현:** 테이블 존재가 발송 완료를 뜻하지 않음. 실제 발송 활성화·비밀 설정 변경은 별도 승인. |
| 정책·CAPTCHA | 약관·개인정보처리방침 본문 공표 및 신규 약관·만 14세 확인 활성화. 계정 삭제·익명화, 보유기간, 국외 처리의 실제 운영 사실 확정 필요. CAPTCHA UI·설정은 준비됐으나 공급자의 실제 거부 동작은 운영 검증 미실행. | **정책 활성화는 사용자 보류.** CAPTCHA 구현 완료와 실제 공급자 검증은 구분. 새 법률 검토나 활성화 승인이 아님. |
| 기존 보안 권고 | 현재 핀 `Werkzeug 3.0.1`·`PyJWT 2.10.1` 갱신 검토, v1 기본 허용(`true`)의 fail-closed 전환 검토, GET 상한·레이트 제한, MIME·CSP 및 장소 검색 제한의 분산 처리. | **후속 검토 권고:** 검증된 새 취약점 목록이 아님. 이번에는 현재 핀만 확인했고 최신 공지는 재점검하지 않았으므로 재개 시 근거·호환성 재확인. |
| 레거시 완전 종료 | v1, 남아 있는 SQLite 자원, 옛 `admin` 경로의 최종 종료·정리. | **로그·보존 확인 후 별도 승인:** 실제 사용과 필요한 백업을 확인해 대상 확정. claim 경로는 이미 폐기되어 남은 작업이 아님. 운영 DB 삭제·이전은 자동 진행하지 않음. |
| 대화상 보류 구상 | 업로드 전 클라이언트 영상 압축(송신 데이터 절약); k3s·BE 호스트 이전; 정식 서비스명·이메일 일괄 변경; 국내 자율 일회성 소액 후원. | **재개 요청 대기:** 압축은 기존 R2 720p 정리와 다른 미구현 작업. 인프라는 구상 단계, 명칭·주소는 미정, 후원은 계획만 저장했으며 개시하지 않음. |

앱 출시와 외부 캘린더 연동은 현재 사용자 제외 범위이므로 할 일에 넣지 않는다. 이미 완료된 기능도 재개발 대상으로 재나열하지 않는다. **미구현 / 사용자 보류 / 검토 권고**를 구분하고, 재개 시 구현 서브에이전트·총괄 리뷰·단위 커밋 및 기존 별도 승인 원칙을 유지한다.
