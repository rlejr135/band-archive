# 국내 자율 소액 후원 도입 검토 계획

상태: **계획만 보관 — 구현·후원 개시 안 함.**

이 문서는 사용자가 확정한 조건과 이전 대화에서 확인한 자료를 정리한다. 새로운 법률·세무 조사 결과나 면세 판정이 아니며, 실제 도입 전 아래 확인사항을 다시 검토한다.

## 1. 확정한 운영 원칙

- 대상은 국내 이용자로 한정한다.
- 영리 목적이 아니라 서버비 등 서비스 운영비 충당 가능성을 탐색한다.
- 후원은 자율적인 일회성 소액 후원으로만 검토한다.
- 후원하지 않아도 서비스를 동일하게 이용할 수 있다. 후원 여부·금액에 따른 기능, 용량, 권한, 가입 승인, 지원 우선순위 등의 차등을 두지 않는다.
- 세액공제용 기부금 영수증은 발급하지 않는다.
- 현재는 후원 안내·계좌·QR을 게시하거나 후원을 받기 시작하지 않는다. 결제·후원 기능도 구현하지 않는다.

### 영수증과 세금에 대한 표현

사용자가 말한 ‘비과세 영수증’은 이 계획에서 **‘세액공제용 기부금 영수증을 발급하지 않음’**으로 정리한다. 안내 문구에도 ‘비과세’, ‘세금 없음’, ‘면세 보장’처럼 세무 판단으로 오해할 표현을 사용하지 않는다.

영수증 미발급과 운영자의 소득 구분·신고 의무는 별개다. 비영리 목적이나 소액이라는 이유만으로 세금 또는 신고 의무가 없다고 결론 내리지 않는다.

## 2. 검토할 수령 방식

우선 후보는 **국내 계좌 송금**이며, 이용자가 토스 등 송금 앱을 사용하는 방식까지 포함해 검토한다. 특정 업체의 결제 상품이나 수령 기능을 채택한 상태는 아니다.

- 기존 `toss.me` 서비스는 종료되었으므로 이 주소를 후원 수령 수단으로 계획하지 않는다.
- 실제 계좌 공유·QR 지원 여부, 수령 방식의 이용 조건 및 자율 후원 용도로 허용되는 범위는 도입 시 해당 플랫폼의 최신 공식 안내로 재확인한다.
- 서비스 계정·멤버십과 입금 여부를 연결하지 않는다. 후원에 따른 자동 역할·뱃지·혜택도 만들지 않는다.
- 공개할 수령인·계좌 정보의 범위는 실제 방식 선정 시 결정한다. 현재 문서에는 계좌나 비밀 정보를 기재하지 않는다.

## 3. 도입 전에 확인·결정할 사항

### 세무·제도 적용 확인

1. **국세청에 확인:** 실제 운영·수령 형태를 설명하고 소득 구분, 신고 의무, 사업자등록 필요 여부를 확인한다. 결과를 확인하기 전에는 면세나 등록 불필요를 단정하지 않는다.
2. **관할 기부금품 담당부서에 확인:** 예정된 안내·모집·수령 형태에 관련 제도가 적용되는지, 필요한 절차가 있는지 확인한다. ‘후원’이라는 명칭이나 소액이라는 이유만으로 적용 제외를 가정하지 않는다.
3. 확인 결과와 적용 조건을 기록하고, 필요 절차가 있다면 이행한 뒤 개시 여부를 결정한다.

### 운영 방식 결정

- 사용 목적: 서버비 등 어떤 운영비에 사용할지, 목적을 어떻게 안내할지 결정한다.
- 반환·문의: 문의 창구, 반환 요청 접수와 처리 기준을 결정한다. 실제 가능 범위를 확인하기 전에 무조건 반환 또는 반환 불가를 약속하지 않는다.
- 수입·지출 기록: 수령일·금액·관련 지출 등 어떤 항목을 기록할지와 기록 관리·보관 방식을 결정한다. 서비스 회원 정보와 결합하지 않고 불필요한 후원자 정보는 요구하지 않는다.
- 안내 문구: 자율 후원, 미후원자와 동일한 서비스, 사용 목적, 문의·반환 안내, 세액공제용 기부금 영수증 미발급 사실을 명확히 표시한다.
- 최종 검토: 위 확인 결과를 사용자에게 보고하고 실제 도입 방식·안내 내용·개시 여부를 확정한다.
